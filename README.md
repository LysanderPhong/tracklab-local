# TrackLab Local

一个插上 iPhone、在电脑网页里选位置的小工具。

## 为什么做这个？

说实话，最开始就是觉得校园跑有点麻烦，想偷个懒，于是折腾起了手机定位。后来越做越多，索性把固定定位、路线回放和本地网页整理到一起，开源给同样爱折腾的同学。

不过，**能模拟定位，不等于校园跑能算成绩**。目前验证的是设备定位功能，没有验证任何校园跑平台是否认可记录，也不承诺“包过”“不被识别”。

不用注册账号，不用找八位配对码，也不用挤同一个网站。下载到自己的电脑上，插线、打开页面，就可以开始操作。

> 目前还是测试版：Mac + iPhone 有过真机验证，Windows 还没完成真机验证。第一次需要准备运行环境，暂时还没做到解压就能直接用的程度。

## 先下载

**[点这里下载本地版 ZIP](https://github.com/LysanderPhong/tracklab-local/releases/download/v0.5.1-beta/TrackLab-Local-0.5.1-beta.zip)** · [查看版本说明](https://github.com/LysanderPhong/tracklab-local/releases)

下载后先把整个压缩包解压出来，不要在压缩包里直接双击运行。

## 你需要准备什么？

- 一台电脑。目前推荐用 Mac，Windows 的启动脚本也提供了，但兼容性还需要测试。
- 一部 iPhone，以及一根能传数据的数据线。这个包暂时不支持 Android。
- [Python 3.12](https://www.python.org/downloads/)；Mac 已经装过 [uv](https://docs.astral.sh/uv/getting-started/installation/) 的话，也可以直接用它。
- 网络。第一次安装依赖要联网，之后地图和地名搜索也需要联网。

Windows 还需要 Apple 设备驱动。如果电脑本身就认不出手机，得先解决这一步。

## 怎么用？

1. **插上手机并解锁。** 手机上出现“信任此电脑”时确认，按提示开启开发者模式。这些系统步骤还是要自己点。
2. **双击启动文件。** Mac 打开 `一键连接-Mac.command`；Windows 打开 `一键连接-Windows.cmd`。第一次会下载需要的依赖，稍等一会儿。
3. **等浏览器自动打开。** 地址是 `http://127.0.0.1:8769/fixed`。这是你电脑里的页面，不是作者的服务器。
4. **选好位置或路线，再点开始。** 网页会先检查手机是否就绪；插线稍晚的话，点一下“刷新连接状态”。
5. **用完点“恢复真实定位”。** 再打开手机地图看一下，确认位置恢复了。

第一次准备好以后，后面通常就是：**插手机 → 双击启动 → 选位置。** 不用每次重装，也不用重新配对。

如果 macOS 拦截启动文件，先核实下载来源，再按系统提示处理。不需要为了运行它关闭系统安全保护。

## 现在能做什么？

| 功能 | 用法 |
| --- | --- |
| 固定定位 | 选一个位置，设置持续时间，开始后保持在该位置 |
| 动态路线 | 在地图上选点、调整路线，再进行路线回放 |
| 地点选择 | 搜地名、输入经纬度，或者直接在地图上点选 |
| 提前结束 | 随时点恢复，设备重新检查通过后可以再换位置 |
| 收藏地点 | 常用位置保存在当前浏览器里，下次方便找 |

## 可能会遇到的问题

### 为什么“开始”点不了？

先看按钮旁边的提示。手机没就绪、还没选地点、上一轮还在运行，或者恢复还没确认，都可能让它暂时不能点。可以先点“刷新连接状态”；如果提示需要恢复，就先把上一轮处理完。

### 提前恢复以后，能马上换一个位置吗？

可以。恢复指令完成后会自动检查手机，检查通过就能再开始；如果手机断开或检查失败，需要先处理页面提示。

### 关掉网页，是不是就结束了？

**不是。** 网页是操作面板，后台程序还会继续运行。结束时请点“恢复真实定位”，不要把关网页、拔线或强制退出当成恢复按钮。误关页面后，再双击启动文件就能回来。

### 下载下来是不是完全不用安装？

还不是。当前 ZIP 里是源码和启动脚本，不包含 Python。第一次需要装好 Python 3.12（Mac 也可以用 uv），脚本再准备项目依赖。它目前还不是一个签名好的、双击就能装的桌面 App。

### 人多了会不会把作者的服务器挤爆？

本地版的定位操作都在各自电脑上执行，不经过作者的 Render 网站。GitHub 负责提供下载，大家各用各的电脑。

但地图和搜索还是第三方在线服务，不是无限容量，也不是完全离线。搜索词、查询坐标会发给相应的地图服务。

### 一台电脑能同时带好几部手机吗？

目前一个本地服务只支持一个活动定位任务，暂时别把它当成多手机控制台。不同电脑可以各自运行。

### 搜不到学校、宿舍或跑道怎么办？

地名数据不一定全。试试“城市＋地点”，或者直接输入经纬度、在地图上选点，路线也可以自己调整。没有搜到，不代表设备没连接上。

### 启动报错怎么办？

先确认压缩包已经完整解压、Python 版本是 3.12，并且网络正常。Windows 可以重新运行 `安装连接程序-Windows.cmd`。

还不行的话，可以到 [Issues](https://github.com/LysanderPhong/tracklab-local/issues) 贴报错，并写清电脑系统、手机型号和 iOS 版本。日志在 `runtime/desktop-launcher.log`，分享前去掉设备标识、个人位置和其他私人信息。

## 想看代码或自己改？

下面这部分给想继续折腾的同学，普通使用可以跳过。

使用 Python 3.12，在项目目录执行：

```sh
uv sync --locked
uv run python desktop_launcher.py
```

跑测试和打包：

```sh
uv run python -m unittest discover -s tests -q
node tests/test_connection_state.cjs
node tests/test_restart_fixed.cjs
python3 build_release.py
```

压缩包和校验文件会出现在 `dist/`。依赖版本记录在 `uv.lock` 和 `requirements-desktop.txt`，发布包不带本机运行环境、设备配对记录或缓存。

安装依赖中途失败时，可以重新执行 `uv sync --locked`；使用 Python 安装的，则用项目 `.venv` 里的 Python 执行 `-m pip install --require-hashes -r requirements-desktop.txt`。

本地服务只监听 `127.0.0.1`，不开放到局域网。重复启动会复用已有服务；升级前先恢复手机定位并退出旧后台进程，不要在定位运行中覆盖环境。
